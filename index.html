What it does

Search Center is a Safari extension for iPhone and iPad. When you select text on a web page, a small bar of search buttons appears next to Apple's Copy menu. Tap one to search the selected text on that site in a new tab.

You choose the sites: add any search engine, shop or reference site with a search URL, reorder them, and back up your setup.
