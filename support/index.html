Turn it on

  1. Open Settings › Apps › Safari › Extensions.
  2. Tap Search Center and turn it on.
  3. Set All Websites to Allow.
  4. In Safari, select some text. The bar of search buttons appears next to Apple's Copy menu.

Questions

The bar doesn't appear

  • Check the extension is on and All Websites is set to Allow (see above). If you allowed only some sites, the bar shows only on those.
  • In a Private tab, also turn on Allow in Private Browsing in the same settings screen.
  • Safari doesn't run extensions on some pages, such as the Start page, Safari's own pages and some Apple sites.
  • Try reloading the page after turning the extension on.

How do I add a search site?

In Safari, tap the extensions button in the address bar, then Search Center. Under Add engine, enter a name and the site's search address with %s where the selected text goes, then tap Add.

How do I find a site's search address?

Search for a word, for example test, on that site. Copy the address of the results page and replace test with %s. For example: https://www.ebay.com/sch/i.html?_nkw=%s.

Can I reorder, edit or remove sites?

Yes. In the extension's settings, use the arrow to move a site up, the pencil to edit it and × to remove it. Reset to default engines restores the starting list.

Can I show names instead of icons?

Yes. In the extension's settings, set Show in the bar to Names only, Icons only or Icons and names. Automatic picks what fits.

How do I back up or move my setup to another device?

In the extension's settings, under Backup, tap Save as file (or Copy backup). On the other device, tap Import, choose the file or paste the backup, then pick Merge to add to your list or Replace to swap it. Undo last import puts things back.

Does it work on iPad?

Yes, the same way as on iPhone, including with a keyboard and trackpad.

Does it see what I read?

No. Nothing leaves your device until you tap a search button. See the Privacy Policy.
